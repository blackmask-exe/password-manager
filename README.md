# Password Manager

Welcome to the Password Manager project repository. This application provides a simple and secure way to store all your passwords locally, eliminating concerns about internet theft. The passwords are stored in the same folder as the project, ensuring they remain on your local machine.

## Features

- **Local Storage**: All passwords are stored locally within the project directory, enhancing security by avoiding cloud storage.
- **Search Functionality**: Built-in search feature allows for quick retrieval of stored passwords.
- **Clean and Simple GUI**: The application offers a user-friendly interface with no distractions.

## Technologies Used

The Password Manager is built using Python and leverages the following libraries:

- **Tkinter**: For creating the graphical user interface.
- **Other Dependencies**: Listed in the `requirements.txt` file.

## Getting Started

To set up and run the Password Manager locally, follow these steps:

1. **Clone the Repository:**:
   ```bash
   git clone https://github.com/blackmask-exe/password-manager.git
   
2. **Navigate to the Project folder:**:

   ```bash
   cd password-manager
   ```
   
3. **Create a Virtual Environment (Optional but Recommended):**
    ```bash
   python -m venv venv
    ```
   
4. **Activate the Virtual Environment:**
    ```bash
   # On Windows:
   venv\Scripts\activate
   
    # On macOS/Linux:
    source venv/bin/activate
    ```
   
5. **Install required dependencies:**
    ```bash
   pip install -r requirements.txt
    ```
   
6. **Run the application:**
    ```bash
   python main.py
   ```
